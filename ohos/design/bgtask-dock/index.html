aide 鸿蒙端 · 后台任务停靠区改版原型点开详情连体化 · 收起是胶囊 · 展开是一张整卡

痛点：现状 BgTaskDock.ets 里状态条（radius 10、margin 8/2）和任务列表面板（radius 12、margin 6/2）是两张各自描边的卡——点开详情时中间露出一条页底背景缝 + 双层描边，视觉断裂。改法：连体单卡，状态条即卡片头，头部与列表间一条内嵌发丝线；收起时回归胶囊形态；任务列表限高内滚，多任务 + 长输出不再把输入栏顶出屏。屏 1 是现状对照（variant=before，数字对齐现有代码），屏 2–4 是新方案。操作经展台胶囊下发，跨屏同步（主题除外——各屏独立呈现浅/深对照）。

▾结构说明 · 设计要点 · 实施清单 · 未采纳

原型结构 · 单 app 双变体

  • 一个 app.html，URL 参数即初始形态：variant=before|after（现状 / 新方案）、theme、scenario=single|multi|done|failed、open、id。
  • before 不是摆设：两卡的 margin / radius / padding 数字逐项对齐 BgTaskDock.ets 现状代码，屏 1 即「点开详情很丑」的复现。
  • 任务数据形状对齐 ChatBlocks.ets 的 BgTask（command / description / status / output / startedAt / endedAt / truncatedBytes）；输出截断「截头保尾 + …已截断 N 字节 前缀」同 appendBgOutput 语义。
  • 生命周期语义照搬：跨轮次存活、全部完成 ✓/✗ 停留 2.5s 即焚、停留期内新任务取消即焚并清走已结束项。
  • 跨屏同步：胶囊 → postMessage 下发 → 应用后广播 {event:'sync'} → 展台中继给其余屏（主题除外，各屏独立切换）。

设计要点 · 新方案（after）

  • 连体单卡：状态条即卡片头，bar 与任务列表同底色、同描边、同 radius 12，一张卡从收起到展开不断裂。
  • 头/身分隔：内嵌发丝线（box-shadow: inset 0 -1px 0），不加 border 不产生 1px 布局跳动。
  • 展开即把手化：展开态头部整行退化为一条细把手——居中 ▴ 收起箭头、整行点击收起；dot / 标题 / 计数 / 命令全部退场（信息列表里都有，头部只剩「收起」这一个功能）。收起态照旧胶囊摘要。停靠区只消费 bg_task_* 壳任务，与子代理 / 子会话无关（那些走消息流卡片）。
  • 收起 = 胶囊：不展开时外观与现状状态条几乎一致（仅 radius 10→12 统一），肌肉记忆不变。
  • 任务列表限高内滚：max-height 42vh——多任务 + 长输出不再把输入栏顶出屏（现状没有上限）。
  • 失败态可见：状态条圆点接 status_danger（现状恒 ok 绿），「✗ 后台任务已结束」一眼可辨。
  • 输出框 / 终止按钮 / 走表 / 任务间发丝线：全部保留现状形态，本轮只动「卡的结构」。

实施清单（BgTaskDock.ets · 本页只出原型，未动代码）

  • build() 外层合并：把 barView/panelView 包进单卡容器——border + borderRadius(12) + clip + margin(8,12,2)；两个子视图删掉各自的 margin / border / radius。
  • 头/身发丝线：panelView 顶部加 Divider（或 bar 尾随 Divider，随 panelOpen 显隐）。
  • 列表限高：task-list 外包 Scroll + constraintSize({ maxHeight: 屏高 × 0.42 })。
  • barView 把手化：展开态隐藏 dot / 文案 / cmd，居中 chevron-up（现有 SymbolGlyph 旋转 180 复用），整行点击收起，行高约 28vp；收起态胶囊摘要不变。
  • barView 完成态圆点：anyFailed() 时圆点用 status_danger（现状固定 status_ok；仅收起态可见）。
  • 收起半径统一 12：现状 bar radius 10 与 panel 12 不一致，统一为 12。
  • 动效保持：TransitionEffect.asymmetric 300/450 不动；chevron 旋转不动。
  • 零数据面改动：ChatStore / BgTask / 事件流 / 即焚语义全部不动。

未采纳

  • bar 与 panel 之间的「粘连小颈」异形连接件：过度设计，连体单卡已消除断裂感
  • 展开态给头部加底色分区（input_bg 头）：试过视觉显脏，同底色 + 发丝线更干净
  • 每个任务行独立折叠：列表已限高内滚，折叠收益低
  • 输出区 xterm 化：移动端旧决策（纯文本贴尾滚动），不翻案
