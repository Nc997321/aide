会话页排版草案

V1 时间线内瞬态行：工具运行时消息流里出现一行「正在执行 ××」，本轮结束整行淡出消失。历史里永远只有思考卡 + 对话。代价：行的出现/消失会让时间线轻微跳动。
V2 停靠活动卡：运行期在输入框上方停靠一张「正在执行」卡，步骤逐条打勾，回合结束整卡滑走。时间线零跳动，运行过程看得最清楚。
V3 极简状态行：时间线严格只有气泡 / 正文 / 思考入口，运行状态只是输入框上一行小字轮播当前工具。最克制，信息也最少。
三版通用语义：工具事件只进瞬态 liveActivity，不进消息流，回合结束清空（= 不驻留内存）；历史加载时跳过 tool_call 块；卡片一律白底描边、间距走 8 的倍数、图标统一 SVG。
后台任务（bg_task_*，三版同款停靠区）：状态条胶囊有任务才出现（● N 个运行中 + 命令名），点开看任务列表（状态/命令/走表时长/终止）+ 尾部输出贴尾滚动（移动端不做 xterm）。跨轮次存活——回合结束不清，bg_task_ended 才收；全部完成后状态条变 ✓ 停留数秒淡出。桌面端 BgTaskDock 同语义。tasks_update（代理待办清单）是另一个域，未在此演示。
