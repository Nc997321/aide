aide 鸿蒙端原型 · 多主机连接与切换v1 单活连接 · 主机管理中心 + 抽屉切换

按已确认的设计方案出原型：同一时刻只保持一台活动连接，切换 = 复用传输实例换凭据重连。连接页升级为主机管理中心（列表 / 忘记 / 添加），聊天侧切换入口收进抽屉设备卡，切换走半模态 + accent 过渡横幅，会话 / 工作区 / 供应商数据按主机整体换血。三个手机框是同一个 app.html 的 iframe 实例——URL 参数决定初始形态，展台经 postMessage 遥控，切换动作跨屏同步。聊天深度交互不在此重复，见 ../remote/index.html。

原型结构 · 与设计方案的对应

  • app.html = 应用本体：两屏共用一份 DOM 与状态，URL 参数决定初始形态（?screen=hosts / ?screen=chat&drawer=1 / ?screen=chat&sheet=1），与未来 ArkTS 页面一一对应（ConnectPage 升级版 / ChatPage + ChatDrawer + 切换 Sheet）。
  • 三屏同一实例，切换动作经展台 sync 中继跨屏同步（切 heaven-mac 后屏 2/3 同步换血）。
  • 假数据形状对齐多凭据设计：每主机一条记录（did / 凭据态 / 上次连接 / 会话 / 工作区 / 供应商 / 续传位置），活动主机 = connected。
  • 聊天深度交互（流式 / 权限卡 / 后台任务）不在此重复，见 ../remote/index.html；会话页深挖见 ../chat-layout-mock.html。

屏 1 · 主机管理（ConnectPage 升级）

  • 主机列表卡：字母头像着色 + 主机名 + did·平台 + 状态行四态（已连接·正在使用 / 上次连接 x / 正在连接… / 配对已被吊销）
  • 非活动主机右侧 「连接 ›」 affordance；被吊销主机给 重新扫码 按钮（按主机归因，不影响其他主机）
  • 忘记主机：垃圾桶 → AlertDialog 确认（删凭据与续传位置）；删除活动主机 = 断开并忘记
  • 添加主机：扫码（主路径）+ 粘贴配对码兜底；配对成功入列并自动连接
  • 脚注：自动连接上次使用的主机 · 各主机凭据分别保存

屏 2/3 · 抽屉切换入口 + 半模态

  • 设备卡行内右侧 「⇄ 切换主机」胶囊按钮（不占整行）；断开连接 红字收进信息列（断开不删凭据）
  • 切换半模态：主机行（头像 / 名称 / 当前勾选 or 上次连接时间 / 被吊销标红提示）+ 添加新主机 虚线行 + 脚注（凭据独立保存）
  • 切换过渡：accent 横幅「正在连接 x…」+ 消息区压暗 + 输入禁用 ≈1.5s → 完成 toast「已连接 x」+ 顶栏/消息/抽屉整体换血
  • 数据隔离一眼可验：heaven-mac 是 DeepSeek + homepage 工作区，公司工位机是 cpa-local + 周报会话

实施清单（ohos 工程 · 本页只出原型，未动代码）

  • storage：aide-remote-hosts 数组 + aide-remote-active，迁移旧单键 creds；接口 loadHosts/saveHosts/forgetHost/setActive
  • ConnModel：pairWithOffer 按 deviceId 去重覆盖；新增 switchTo(deviceId) 与 onHostChanged 回调；disconnectAll 拆 disconnectActive / forgetHost
  • 会话层复位联动：authed 且 hostChanged 时 chat/sessions/workspace/provider/automation 全部清缓存重拉（防旧主机数据串台）
  • UI：ConnectPage 重构为主机列表；ChatDrawer 加切换行 + 断开；新增 HostSwitchSheet 半模态
  • 切换时序：先停 TTS/听书/朗读 再 disconnect（防旧主机声音串播）
  • autoConnect / onForeground 补连：读 activeDeviceId 对应凭据

未采纳 / 留待 v2

  • 多活并行连接（每 Host 一个 transport、后台主机收推送）：改造面大，v1 单活；存储结构已按主机分行，v2 无需二次迁移
  • 非活动主机实时在线状态：不保持连接就无实时态，只诚实显示「上次连接」
  • 主机拖拽排序 / 分组：列表 ≤5 台时无必要
  • 主机级独立身份密钥：现有设计身份跨 Host 复用，配对更省事
