▾结构说明 · v3 变更 · 工作区重设计 · 实施清单

原型结构 · iframe 拆分（为什么好维护）

  • app.html = 应用本体：三屏共用一份 DOM 与状态，URL 参数决定初始形态（?screen=connect / ?screen=chat&drawer=1&demo=0）。改动几乎只发生在这一个文件，且与未来 ArkTS 页面一一对应（ConnectPage / ChatPage + 抽屉弹层）。
  • index.html = 展台：手机框 + iframe + 演示胶囊，postMessage 遥控（含三屏状态互相同步）。纯布景，基本不用动。
  • 单独打开 app.html 也能玩：默认聊天屏 + 自动流式演示。
  • 会话页深挖（权限应答卡 / 后台任务 / 思考卡限高）继续留在 ../chat-layout-mock.html，本页不重复。

屏 1 · 连接 / 配对（对照 ConnectPage，结构不变）

  • 中继 URL + 6 位配对码、连接按钮、五种状态卡（文案与现实现一致）
  • 已配对自动连接；连接成功直达聊天主屏（v3 起不再落会话列表整屏）

屏 2 · 聊天主屏（v3 新导航）

  • 聊天升主屏：会话列表不再是独立整屏（现 SessionsPage 退场）
  • 顶栏副标题：工作区色点 + 名称，纯展示不响应点击；工作区 / 供应商切换都在抽屉里（离线时供应商切换给 toast）
  • 模型 chip：输入工具行最左，列表跟随供应商（别名 / 真实 id 对齐桌面 ModelOption），切供应商自动回落该供应商的记忆/默认
  • 思考程度 chip：模型 chip 右侧，三档，会话级、随下一条消息生效；usage 尾注跟随当前档
  • 顶栏右侧 ⏹ 停止会话（interrupt_session 语义）：回复中变红可点，中断后残段冻结 + 系统分隔线；＋ 新会话 收进抽屉「历史会话」标题行（刷新左侧）→ 居中空态（发往当前工作区提示）
  • 消息区语义：思考卡可折叠；Edit/Write 写盘落常驻折叠行（铅笔图标 + 路径，运行中转 spinner、完成定稿，始终显示不可展开，历史重载同形）；读/搜/命令类工具只走瞬态行，回合结束淡出不进历史；断线橙横幅 + 输入禁用，重连 toast + 系统分隔线

屏 3 · 抽屉 + 工作区重设计（替代 remote-pwa 版式）

  • 设备卡：logo + 设备名 + 连接状态；供应商徽标为唯一切换入口，点开半模态
  • 工作区卡（重设计）：字母头像按工作区着色，名称 / 路径 /「N 个会话 · 已启动 / 回复中 / 待确认」计数一眼可读，右侧「切换 ›」明确 affordance
  • 切换弹层（重设计）：半模态工作区选项卡（色彩头像 + 路径 + 会话数 / 三态计数 + 选中描边），脚注注明工作区由桌面 aide 管理
  • 会话项：名称 + 预览 + 相对时间 + 状态点（待确认 橙 / 回复中 绿 / 已启动 蓝，只留点不带文字，颜色语义同工作区卡计数）；点击直达该会话；底部搜索过滤当前工作区

实施清单（ohos 工程 · 本页只出原型，未动代码）

  • 导航：Index authed → 直达 ChatPage（最近会话 / 空态）；SessionsPage 整屏退化为抽屉组件（mask + panel 自绘，或 Navigation SidePathContainer）
  • 新组件：Drawer（设备卡 + 会话列表 + 搜索）、ProviderSheet（抽屉徽标单入口）、EffortChip（输入工具行）、WorkspaceCard + WorkspaceSheet（按本页版式）
  • 时间线：Edit/Write 常驻折叠行——tool_use_start 即入消息 blocks（spinner 态），tool_result 回填定稿；历史映射保留这两类 tool_call，其余工具维持瞬态行语义
  • 协议缺口（与 PWA 共用，见 remote-pwa 对照卡）：ListProviders / SetActiveProvider、send_message 扩展 effort、event provider_changed、list_sessions 扩展 last_preview / started / pending_confirm（抽屉会话徽标三态的数据来源）
