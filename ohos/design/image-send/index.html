附件能力对照鸿蒙系统能力：PhotoViewPicker（图库选择器 · 图片/视频免权限多选，系统选择器自带拍摄入口）、CameraPicker（拉起系统相机拍照）、DocumentViewPicker（任意格式文件）；消息链路对照 remote-pwa ImageAttachment（图先文后 · 上限 5 个）。UI 沿用鸿蒙端浅色原生风格（token 镜像 entry color.json）。三个手机框是同一个 app.html 的 iframe 实例——URL 参数决定初始形态，展台经 postMessage 遥控演示，模型 / 思考程度改动跨屏同步；也可单独打开 app.html 交互。会话页基础版式见 ../remote/index.html。

原型结构 · iframe 拆分

  • app.html = 应用本体：三屏共用一份 DOM 与状态，URL 参数决定初始形态（?state=attach / picker / sent）。改动几乎只发生在这一个文件，与未来 ArkTS 页面一一对应（ChatPage 输入区扩展 + PicturePicker / ImageViewer 弹层）。
  • index.html = 展台：手机框 + iframe + 演示胶囊，postMessage 遥控；模型 / 思考程度跨屏同步。纯布景，基本不用动。
  • 单独打开 app.html 也能玩：默认消息流 + 识图搜索自动循环演示。
  • 会话页基础版式（思考卡 / 工具行 / 抽屉导航）留在 ../remote/index.html 与 ../chat-layout-mock.html，本页只叠加图片能力。

屏 1 · ＋ 菜单与附件条

  • ＋ 在工具行最右端（思考程度右侧、发送按钮正下方），点开弹出菜单：拍照 / 图片 / 视频 / 文件（对应 CameraPicker / PhotoViewPicker·IMAGE / VIDEO / DocumentViewPicker）
  • 附件条 64px 缩略图混排：图片、视频（时长角标）、文件（扩展名徽标横卡），移除角标 + 续选格，上限 5 个
  • 选中的图片/视频逐张「编码中」转圈（模拟重编码），未完成时发送禁用；文件即时
  • 附件先文字后；可只发附件不带文字，placeholder 提示「问问这些内容…」

屏 2 · 选择面板（三段）

  • 顶层分段 图片 / 视频 / 文件；图片段含相册 tab：最近 / 截屏 / 相机（截屏相册直达系统截屏）
  • 图片/视频走 PhotoViewPicker（免权限 · maxSelectNumber 5），视频以首帧缩略图 + 时长呈现
  • 文件段走 DocumentViewPicker：列表行（扩展名徽标 + 名称 + 大小 + 日期），多选角标计数
  • 角标计数 + 选中描边 + 完成按钮带数量；面板内再点已选项即取消；取消不落任何附件

拍照（CameraPicker）

  • cameraPicker.pick 拉起系统相机（CAMERA_POSITION_BACK · PHOTO），拍完 uri 直接回传应用——无需申请相机权限
  • 原型交互：全屏取景（九宫格辅助线）→ 点快门 → 白闪 → 照片进附件条（走同一条重编码链路）
  • 与系统图库选择器右上角的「拍摄」入口同源：都是拉起系统相机后 uri 回传

屏 3 · 消息栅格 / 识图搜索

  • 栅格：1 张原比例（≤200×220）/ 2 张 132² / 3+ 张三列 92px；视频卡（首帧 + 时长 + 播放钮）与图片同格，文件卡跨满列横条；点图/视频全屏带「N / i」计数
  • 识图搜索演示：构建报错截图 + 「搜一下这个报错怎么解决」→ 模型读图（TS2322 · ChatModel.ets:128）→ 自行发起 WebSearch → 给出修复清单
  • 附件回执按类型分列工具行（images / videos / files）；纯文本走常规回复；usage 尾注 effort 档随思考程度实时替换

模型守卫 · image_input_rejected

  • 选中不支持图片的模型（如 deepseek-v4-pro）时，发送按钮退化为 「模型不支持图片」守卫行，点守卫行直接打开模型浮层
  • 拦截演示（协议 event: image_input_rejected + rollback）：消息短暂出现在流里 → 整条退回输入框 → 图片回附件条 → 系统分隔线说明 → 自动弹模型浮层
  • 切换回支持图片的模型后守卫行消失、恢复发送

实施清单（ohos 工程 · 本页只出原型，未动代码）

  • 协议：SendMessageParams.images 放开（api.ets 已占位），图先文后；新增 attachments（视频/文件：uri + 名称 + 大小 + 媒体类型）；ChatEvents 路由 image_input_rejected / image_input_rollback（退回输入框不丢内容）
  • 选图：PhotoViewHelper（PhotoViewPicker · IMAGE/VIDEO · MULTI · maxSelectNumber 5 · 免权限）+ FilePickerHelper（DocumentViewPicker · 任意格式）+ CameraHelper（cameraPicker.pick · PHOTO · 免权限）
  • 编码：imageEncode（pixelMap → JPEG 长边 1568 · 质量 0.85 → 裸 base64 → ImageAttachment，对齐 remote-pwa src/imageEncode.ts）；视频取首帧做缩略图，文件读字节 base64
  • UI：AttachmentStrip（输入区混排）、PlusMenu（工具行右端）、PickerSheet（三段半模态）、CameraSheet、ImageViewer（全屏 + 计数）、ChatBlocks 加 ImageBlock / VideoBlock / FileBlock
  • 守卫：模型能力表（img: bool）→ 发送按钮降级守卫行 + 拦截回退动画（附件全类型生效）
