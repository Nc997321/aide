原型结构 · v3 底稿的增量层

  • 底稿不动：连接屏 / 抽屉 / 工作区 / 供应商切换全部沿用 ../remote/index.html（app.html 由底稿字节级复制后只加语音增量）。
  • 喇叭 chip：挂在每条 assistant 消息末尾（正文之后），三态 = 播报中（均衡器）/ 重播 / 永久关。
  • 权限横幅：aide 请求权限时顶在离线横幅下方，播报固定模板，带允许 / 拒绝按钮。
  • 静默演示：展台默认用「均衡器 + 模拟时长」演示播报节奏；开「真实发声」后走 Web SpeechSynthesis（真机上对应小艺）。
  • 开关状态（tts）随既有 sync 通道跨屏同步，且记入 localStorage 模拟持久化。

喇叭状态机（持久开关，无设置页）

  • 默认开：回复完成自动播报正文，chip 图标转为均衡器动画（accent 底）。
  • 播报中点 chip：立即停止 + 永久关闭（持久化），chip 变虚线灰态静音图标。
  • 关着点 chip：永久打开并重播该条。
  • 开着点其他条目：只重播那条，不动开关。
  • 打断规则：新播报打断旧播报；发新消息 / 切会话 / 停止会话 / 新会话空态都会先停旧播报。
  • 纯图标：喇叭 / 静音 / 均衡器即三态，无文字标签；点击后 toast 反馈结果。

播报内容（只读正文）

  • 代码块 → 「（代码略）」；图片跳过；链接取文字；标题 / 引用 / 列表 / 粗斜体 / 删除线 / 表格线等 Markdown 标记全部剥掉。
  • 单次 10000 字封顶（对齐 textToSpeech 单次上限）。
  • 思考卡 / 工具行 / usage 尾注不读；用户消息不读。

权限播报模板

  • 固定模板：「需要确认。aide 请求{动作}：{单行摘要}。请回到手机处理。」
  • 动作映射：Bash→运行命令 · Write→写入文件 · Edit→编辑文件 · webfetch / web_search→访问网络 · 其余「执行 X 操作」。
  • 横幅本体可点：播报中点横幅 = 停止并永久关闭（与喇叭 chip 同语义）；允许 / 拒绝应答后横幅收起。
  • 提问类（AskUserQuestion 型请求）：真机播第一题文本，本原型未展开。

实施清单（ohos 工程 · 本页只出原型，未动代码）

  • TtsModel 单例：Core Speech Kit textToSpeech，createEngine 走 zh-CN + interaction-broadcast；speak 用 queueMode:0, playType:1（合成即播）；listener 按 requestId 过滤（stop 会先 onComplete 再 onStop，两回调都会来）。
  • 持久化：preferences 记 tts_enabled（默认开）。
  • SpeakChip 组件：三态渲染（playing / on / off），点击语义照抄本页状态机。
  • ChatStore：回复完成钩子 → 正文转纯文本（本页 speechText 的 ArkTS 版）→ speak；新回复开播前先 stop 旧播报。
  • PermissionSheet：待确认项到达 → 动作映射 + 单行摘要 → 模板播报 + 横幅；应答 / 切走即停。
  • 生命周期：切会话 / 离开 ChatPage / interrupt_session → tts.stop()。
  • 异常：模拟器无小艺引擎 → 创建失败 1002300005，降级静默 + toast 提示；1002300007 服务异常重建引擎；无需任何权限声明。
