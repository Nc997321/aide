LSP 标题栏入口 — 3 个原型变体

需求：把 LSP 从设置面板搬到标题栏通知旁，样式参考「活跃会话」。跨语言多行（一个项目同时有 Rust/TS/Java/Go…）、 每行显示 server 状态、未安装的 server 提供安装指引（命令 + 链接）、可编辑排除目录。 三个变体差别在入口形态、安装指引呈现、排除目录位置。模拟数据：Rust/TS 已就绪，Java/Go 未安装。

变体 A

图标按钮 · hover 悬浮面板

入口 = 图标 + 汇总状态点（绿=全就绪 / 黄=有缺），鼠标悬停弹出窄面板，与活跃会话同款交互。安装指引行内展开，排除目录折叠区。

变体 B

常驻徽章 · 点击展开（安装指引内联）

入口 = 常驻徽章，直接显示各语言状态（✓/✗），不用点开就知道缺什么。点击弹出面板：安装指引不折叠直接内联，排除目录常驻底部。

变体 C

图标入口 · 双区宽面板（安装走浏览器）

入口 = 图标 + 状态点（同 A），面板更宽分两个卡片区：上「语言服务器」、下「排除目录」。安装指引不内联，给「安装指引」外链按钮直接跳浏览器。
