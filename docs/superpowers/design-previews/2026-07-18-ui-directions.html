Aide UI「高级感」方向对比

同一主窗口 mock（标题栏 + 会话列表 + 对话区 + 输入框）× 4 个方向。仅表达配色 / 层次 / 光影 / 排版气质，非像素级还原。字体走 Google Fonts CDN，加载失败会回退系统字体。

① Linear / Raycast 式深邃
深灰蓝多层底 + 发丝边框 + 顶光内描边（inset highlight），靛蓝强调色带辉光；Inter 紧凑字距 + 全大写微型标签。签名元素：每个浮起表面的「顶部 1px 受光」。专业、锐利、工具感最强。 Inter + JetBrains Mono
② 暖色基础精修
保留 Aide 现有琥珀血统并加深层次：更暗的底色、暖色发丝边框、渐变琥珀按钮；中文用 Noto Sans SC 细字重拉开对比。签名元素：对话区顶部一蓬暖色环境光晕，像台灯照在桌面上。改动最小、辨识度最延续。 Inter + Noto Sans SC + JetBrains Mono
③ 毛玻璃 / 透明感
窗口底层铺一层极光渐变，所有面板半透明 + backdrop-blur，光从玻璃后面透上来；面板像浮在雾气上。签名元素：穿透整个窗口的极光背景。最「哇塞」，但 Tauri 需开透明窗口 + 性能要实测，代码块/终端区域要做不透底处理。 Inter + JetBrains Mono
④ 灰阶极简
纯灰阶、零彩色干扰：层级全靠明度与发丝分割线，白色就是唯一强调色（反色主按钮），功能色只留给状态点。4px 锐利圆角、负字距标题、全大写标签。签名元素：版式纪律本身。最克制，也最考验间距与对齐功力。 Inter + JetBrains Mono
