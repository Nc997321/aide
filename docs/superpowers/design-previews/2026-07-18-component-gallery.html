新增质感槽位提案 · ThemeTokens 扩展
以下槽位加入 ThemeTokens，组件内统一引用；旧主题文件补默认值即可
Token 槽位作用效果预览
highlightInset浮起表面的顶部 1px 受光（按钮/卡片/菜单/模态共用）
accentGradient主按钮/选中态/开关的渐变强调（暖色=琥珀渐变，靛蓝=蓝紫渐变）
accentGlow主按钮与关键焦点的彩色辉光投影
accentRing输入框/焦点环
ambientGlow对话区顶部的环境光晕，空间的「主光源」
borderStrong悬停/浮层用的次强边框（现有 border / borderSubtle 之外补一档）
ease / easeT统一动效曲线 cubic-bezier(.2,.8,.2,1)，140–160mscubic-bezier(.2,.8,.2,1)
surfaceBlur 后门面板背景模糊，默认 "none" 零成本；玻璃主题给 blur+saturate 一处开启全局毛玻璃（点顶部「玻璃」验证）—
ambientScene 后门应用根层环境场景（极光渐变画在面板后面），默认 "none" 走 bgDeep 纯色；代码/终端/diff 编辑区用深实底 token 豁免透明—
