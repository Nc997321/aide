# UI 质感精修实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按已确认规格 `docs/superpowers/specs/2026-07-18-ui-polish-design.md` 完成 Aide 的 UI 质感精修：ThemeTokens 扩展（含毛玻璃后门）、warm-dark 暖色精修、组件层三批改造、统一 diff 行语言、字体系统本地化、品牌标与「流光」思考动画。

**Architecture:** 主题是 token、组件是实现。所有质感手法封装在组件层并只引用 `--aide-*` 变量；`ThemeTokens` 新增 10 个槽位（8 质感 + 2 玻璃后门，既有主题给惰性默认值）。权威样式源 = 已入库的组件陈列页 `docs/superpowers/design-previews/2026-07-18-component-gallery.html`（下称 **GALLERY**），逐区块移植，不在计划里重复几千行 CSS。

**Tech Stack:** Vue 3 + TypeScript + Tailwind（无颜色工具类）、@fontsource 本地字体、CodeMirror 6（merge/search）、xterm、vitest。

## Global Constraints

- **GALLERY 变量映射规则**：GALLERY 中的 `--foo-bar` ≡ 应用内的 `var(--aide-foo-bar)`（如 `--highlight-inset` → `var(--aide-highlight-inset)`）；`color-mix()`、`rgba()` 原样保留。
- **移植规则**：保留组件现有 DOM 结构与 props，只替换/新增样式；新增视觉变量一律走 token，禁止硬编码 hex；禁止 `if theme ===` 分支。
- **玻璃后门**：每个面板容器的根选择器（卡片/菜单/模态/输入盒/工具块/侧栏/标题栏等）统一加一行 `backdrop-filter: var(--aide-surface-blur);`（普通主题为 `none`，零开销）。弹层类（tooltip/下拉菜单/模态）同样加。
- **动效**：所有 transition 用 `var(--aide-ease-t)`；新增 @keyframes 必须配 `@media (prefers-reduced-motion: reduce)` 静止分支。
- **会话脉冲豁免（用户硬性要求）**：会话状态点的现行脉冲效果（`AStatusDot.vue` 的 `a-dot-pulse` 2s 及其在 TitleBar / SidebarLeft 会话状态上的表现）**保持原样**——关键帧、时长、颜色逻辑一律不动；只允许优化脉冲以外的视觉点。
- **xterm / 编辑器动态 DOM 样式放非 scoped `<style>` 块**（项目既有约定）。
- **字体**：本地 @fontsource，禁止 CDN；等宽栈常量 `MONO_FONT_STACK` 见 Task 2。
- **GALLERY 区块锚点**：移植时用注释行定位，如 `/* ═══ 按钮 AButton ═══ */`（实际为 `/* ═══════════ 按钮 AButton ═══════════ */`，grep "按钮 AButton" 即可）。
- 每个 Task 完成后：`pnpm build`（含 vue-tsc 类型检查）必须通过；涉及逻辑改动的 Task 另需 `pnpm test`。

```ts
import type { ThemeTokens } from "./tokens";

/** camelCase token 名 → --aide-kebab 变量名（colorScheme 除外，见 applyTheme 特判） */
export function cssVarName(key: string): string {
  return `--aide-${key.replace(/([A-Z])/g, "-$1").toLowerCase()}`;
}

export function applyTheme(tokens: ThemeTokens): void {
  const root = document.documentElement;
  for (const [key, value] of Object.entries(tokens)) {
    // colorScheme 不是 --aide-* 变量，而是浏览器原生 `color-scheme` 属性
    if (key === "colorScheme") {
      root.style.setProperty("color-scheme", value);
      continue;
    }
    root.style.setProperty(cssVarName(key), value);
  }
}
```

```ts
/** 全局等宽字体栈（本地 @fontsource 打包，不走 CDN） */
export const MONO_FONT_STACK = "'JetBrains Mono', 'Cascadia Code', 'Fira Code', 'Consolas', monospace";

const LEGACY_MONO_DEFAULT = "'Cascadia Code', 'Fira Code', 'Consolas', monospace";

/** 读取持久化 fontFamily：未设置或仍是旧默认字面量 → 新默认；用户自定义 → 保留 */
export function resolveFontFamily(stored: string | null | undefined): string {
  if (!stored || stored === LEGACY_MONO_DEFAULT) return MONO_FONT_STACK;
  return stored;
}
```
