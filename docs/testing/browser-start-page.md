# 浏览器开始页验收

## 已确认的界面

- 新标签页直接显示「创作与预览」「最近使用」，不显示「开始」标题或引导说明。
- 空地址栏的「输入网址」居中；输入真实网址后左对齐，回车导航。
- 收藏栏默认隐藏；右上角三点菜单提供新标签页、收藏夹、历史记录、导入收藏。
- 「显示收藏栏」只在收藏夹内部，偏好重启后保留。
- 最近使用支持全部／网页／创作／媒体筛选，移除记录后可撤销，不删除源文件或会话。

## 数据与恢复边界

- 历史保存在 GUI 的浏览器存储，按 `hostApi.identity().key` 隔离，每个 Host 最多 200 条；不向手机增加协议或能力。
- 网页只记录成功导航，常驻订阅覆盖开始页面板首次挂载前发生的导航。
- 媒体通过源文件与原会话重新打开；不保存含一次性凭据的播放器 URL。
- 尚未定名的新草稿只保留内存记录；`session_init` 后随草稿别名转换为真实会话引用，再写入持久历史。
- 创作入口补充当前会话的草稿，保留已有文字与附件，不自动发送、不启动渲染。
- 记录从本次实现启用后开始积累；不猜测旧会话是否为视频工程，也不扫描历史内容补造记录。

## 自动化复跑

在仓库根目录执行：

```sh
pnpm exec vitest run src/components/Browser src/composables/browser src/composables/useMediaPreview.test.ts src/composables/useFileResolver.test.ts src/composables/usePaneLayout.test.ts src/composables/useRightPanel.test.ts src/utils/browser.test.ts
pnpm build
pnpm check:tauri-imports
```

真实组件隔离夹具（不是手抄样式，不连接实际 Host、不发送消息）：

```sh
pnpm exec vite --host 127.0.0.1 --port 5199
```

- 浅色宽栏：`http://127.0.0.1:5199/docs/prototypes/_harness/browser-start-live.html?theme=smoky-pink-glass`
- 暖暗窄栏：`http://127.0.0.1:5199/docs/prototypes/_harness/browser-start-live.html?theme=warm-dark&width=380`
- 夹具使用独立的 `fixture:browser-start` 存储键；示例数据不混入实际 Host 的历史。

## 原生窗口剩余走查

实现时没有重启用户工作会话。以下是原生 WebView2 的剩余验收，不把隔离 Chrome 或 jsdom 结果当成其通过。

使用装载新前端的空会话；无需发送付费模型请求，也不要为此重启正在工作的长会话。人工操作即可；如交给 agent 操作真实桌面，必须另行取得明确的电脑操作授权。

1. 打开浏览器新标签页，确认布局与空提示；输入空白后回车不创建网页，空页收藏按钮禁用。
2. 输入一个测试网址并访问；另开新标签页，确认成功网页进入最近使用，失败网址不入历史。点击记录可再次打开。
3. 网页正在显示时展开三点菜单、收藏夹和历史记录；确认浮层没有被原生网页遮住。Esc 只关闭最上层，关闭后网页恢复位置和滚动状态。
4. 在收藏夹内部开启收藏栏，确认原有目录、图标、导入与拖动行为可用；关闭收藏栏并重新打开收藏夹，确认开关状态一致。
5. 当前会话先留一段未发送草稿，再通过制作／剪辑入口填写要求；确认原草稿保留、新要求已追加，没有自动发消息。浏览器最大化时，应解除最大化让会话输入框可见。
6. 通过「打开媒体」选择当前 Host 上已有的视频或音频；选片段／截帧／反馈仍回到原会话草稿。再从最近使用打开，确认恢复的是源文件而非临时地址；源文件失效时应提示错误，不伪报成功。
7. 移除一条最近记录再撤销，确认源文件／会话未被删除。切换筛选与搜索历史，确认结果正确。
8. 有现成第二个 Host 时，分别查看历史与收藏栏偏好，确认不串记录；没有第二个 Host 时标记未验，不为本项额外搭环境。

走查后将实际通过／未通过／跳过及错误证据补到本节；不要仅写「已验收」。
