运行配置下拉 · 交互原型

点击标题栏左侧 ● iotPlatform ▾ 试试看 — 这是可交互的
  • 17 个模块全部可见：列表 max-height:320px + 内部滚动，不再被裁掉。
  • 搜索筛选：在框里输入 eureka / service 立即收窄。
  • 每行可单独运行：鼠标悬停某行，右侧出现 ▶，点它直接运行该模块（不改变当前活动配置）。
  • 点行名 = 设为活动配置（左侧 ✓ + 名字变 accent 色，沿用现在的选中样式），主 ▶ / ⏹ / ↻ 按钮作用于活动配置。
  • 运行状态只看主按钮：启动前是绿色 ▶ 三角，启动后变红色 ⏹ 方块——列表里不再放状态点。
  • 悬停看完整命令：鼠标停在行上会浮出 mvn -pl … && java -jar …，列表本身不再铺满长命令。
  • 键盘：↑↓ 移动高亮、Enter 运行高亮项、Esc 关闭。
