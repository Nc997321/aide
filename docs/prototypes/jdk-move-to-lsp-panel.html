JDK 按工作区走 — 原型 v2

核心心智：一个工作区 = 一个 JDK（Maven/Gradle 反应堆构建只有一个启动 JDK），所有模块共享，消灭「每点一个模块提示一次」。 存储：state.json → workspace_jdks[工作区key] = jdk路径（复用 lsp_workspaces 范式）；空 = 系统默认。 存量 per-config env.JAVA_HOME 自动迁移：第一个值提升为工作区 JDK，并从所有配置剥除（保留其他 env 键）。 工作台终端不注入（v1 只管 run 进程）。
