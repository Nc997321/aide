设计批注

1入口 = 侧栏分区树
可折叠根分区（三角箭头 14px 项目约定），新功能 = 追加根节点（右下「连接器」示例分区演示扩展方式）。两区可同时展开——看会话时也能瞥见任务在跑（分区头呼吸点）。实现可复用 ATreeItem/TreeNodeItem。
2运行记录一等公民
主区详情即运行账本：成功率 / 总成本 / 平均耗时 / 缓存命中统计条 + 每次运行的触发方式、轮数、成本、摘要，点行进只读转录（复用会话查看器）。
3playbook 卡片
手册状态就地可见：未提炼 / 已就绪 / 待重新提炼。就绪后每次运行省 3–5×（示例：探索 16 轮 $0.147 → 手册 4 轮 $0.012），卡片直接展示这笔账。
4预算护栏
轮次上限 + 成本上限，任一触顶即中止、记失败、发通知（SDK maxTurns / maxBudgetUsd，M2 已透传）。
5权限预设 + 连接器
只读 / 工作区写入 / 完全访问三档（底层三层纵深：tools 可见性 + policy hook 裁决 + canUseTool 兜底，M2 已实现并冒烟验证）。连接器多选 = 预授权 MCP。
6错过补跑策略
客户端内调度的配套：启动发现错过触发点时 补跑 / 跳过 / 询问（M2 已实现 catchup/skip，ask 走通知）。v1 不做系统级调度。
7模型 / effort 按任务指定
不继承主会话。默认 Sonnet + 中档；Fable 档带成本警告（自动化是流程重量匹配任务的典型场景）。
8完成通知
系统通知带轮数+成本摘要（手册模式下数字直接体现省钱效果），点击跳该次运行。失败必通知。
9实时输出 = 聊天 tab
运行本身就是会话：点运行行用现有 ChatPanel 开该 sessionId，流式输出/完整转录零新代码。v1 不强制只读。
