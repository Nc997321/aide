文件树装饰规则

· M 修改 → 暖黄（warning）｜ A 已暂存新增 → 绿（success）｜ D 删除 → 红 + 删除线 ｜ U 未跟踪 → 蓝（info）｜ C 冲突 → 红
· 目录：任意子孙有变更 → 名称变聚合色（弱化 75% 透明度，与文件区分），不带字母徽标（VSCode 行为）
· 字母徽标只出现在文件上，右对齐

Git 面板新增

· 冲突提示条：有冲突文件时置顶红色 banner
· Amend 勾选框：commit 输入框下方，勾选后提交 = git commit --amend
· Stash 区块：列表 + 每行 Apply / Pop / Drop（Drop 二次确认）；头部「Stash 当前改动」可填备注
· Fetch ⟳：手动 fetch；Pull/Push 按钮带 ahead/behind 计数（Pull ↓2 = 远端领先 2 条）
· 加载更多：log 分页，每次追加 50 条
