功能覆盖对照（计划 §功能清单）

屏 1 · 连接/配对

  • 中继 URL 输入框（标注"记住上次输入"）
  • 6 位配对码输入框（数字键盘、大字号居中）
  • 连接按钮（连接中带 spinner 禁用）
  • 五种状态：连接中 / 已连接 / 设备离线自动重试 / 配对码无效（输入框标红抖动）/ 需重新配对
  • 已配对自动连接：底部常驻"本设备已配对"指示

屏 2 · 会话列表

  • 顶部连接状态 pill（已连接 / 设备离线，可切换预览）
  • 刷新按钮（点击旋转）
  • 工作区选择器：顶栏下方常驻当前工作区 chip（名称 + 路径），点击弹出底部弹层；切换后会话列表立即刷新（各工作区假数据不同，可观察列表变化）
  • 新会话发往所选工作区：FAB 新建的会话归属当前工作区
  • 会话项：名称 + 最后消息摘要 + 相对时间
  • 新会话入口：右下 FAB（计划中"进聊天屏直接发消息即创建"）
  • 进行中的会话显示 "回复中" 实时徽标

屏 3 · 聊天

  • 顶栏：返回 + 会话名 + 连接状态点
  • 用户消息右侧气泡；助手左侧块状内容
  • 文本块流式逐字 + 闪烁光标；思考块折叠；工具块折叠 + 进行中/成功/失败三态徽标；子代理一行摘要；错误块红卡
  • 历史与流式同列表（上方历史、下方实时演示）
  • 输入框多行自增高；未连接 / 回复中禁用发送
  • 断线：顶栏状态点 + 橙色横幅；重连后 toast + "历史已刷新"分隔线（对应 load_messages 补齐缺口）
