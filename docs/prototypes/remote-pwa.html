功能覆盖对照（v3 变更 + 协议缺口）

屏 1 · 连接/配对（不变）

  • 中继 URL + 6 位配对码、连接按钮、五种状态
  • 已配对自动连接；连接成功直达聊天主屏（v3 起不再落会话列表屏）

屏 2 · 聊天主屏（v3 新导航）

  • ☰ 打开抽屉（Kimi 式；会话列表不再是独立整屏）
  • 供应商 pill：连接状态点 + 当前供应商名 + caret，点出底部弹层切换；离线时点击给 toast 提示
  • 思考程度 chip：输入区工具行（对齐桌面输入框工具栏 effort 选择器）→ 五档自 chip 向上浮出；会话级，离线也可切（随下一条消息生效）；usage 尾注跟随当前档
  • ＋ 新会话入顶栏（FAB 取消）→ 居中空态（logo + 发往当前工作区提示）
  • 消息区：文本流式 + 光标 / 思考折叠 / 工具三态徽标 / 子代理行 / 错误块 / usage 尾注（同 v2）
  • 断线：pill 点变橙 + 橙色横幅 + 输入禁用；重连 toast + 分隔线

屏 3 · 抽屉（Kimi「历史会话」位）

  • 设备卡：aide logo + 设备名 + 连接状态 + 断开按钮
  • 供应商徽标（Kimi「Allegretto」位）：与顶栏 pill 开同一个弹层
  • 工作区 chip + 底部弹层切换（v2 能力搬进抽屉，假数据按工作区隔离）
  • 会话项：名称 + 预览 + 相对时间 + 回复中徽标；点击直达该会话
  • 底部搜索框：输入即过滤当前工作区会话

实施清单 · 协议新增（remote-pwa / protocol.rs）

  • ListProviders → Providers{ providers:[{id,name,icon}], active_id }（桌面 get_providers + get_active_provider_id 透传，SystemDefault 置首对齐 displayList）
  • SetActiveProvider{ provider_id } → 桌面 set_active_provider_id；回最新 Providers
  • send_message 扩展 effort 字段（会话级；缺省 = 桌面当前会话档）；每轮徽标链路已通（message_stop 透传 effort）
  • 可选：桌面标题栏切换时推 event provider_changed，手机 pill 同步
  • 可选：list_sessions 应答扩展 last_preview（抽屉会话项预览行）
  • 导航：authed 后直达聊天（最近会话 / 空态），SessionList 视图由抽屉组件取代

未采纳（Kimi 有、我们没有对应能力）

  • ⋮ 更多菜单：无对应功能清单
  • 语音输入按钮：协议无音频链路
  • 账号头像体系：aide 是单设备桌面，用设备卡代替
