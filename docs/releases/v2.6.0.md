# Aide v2.6.0

## Aide 市场

- 新增「Aide 应用」入口，与 Agent 插件和语言服务器共用市场页面。应用安装到当前窗口连接的 Host。
- 在应用列表安装、更新、启用、禁用或卸载应用，同时查看本地安装与当前工作区的开发版。
- 官方应用目录使用 Ed25519 签名，安装包使用 SHA-256 校验。兼容的应用可以独立于 Aide 本体发布。

## 终端与项目任务

- 终端支持内联自然语言生成命令，并提供执行前的预览、修改和拒绝入口。支持从 Windows PowerShell 进入 WSL Bash 后使用。
- 项目任务支持从项目配置发现常用命令，并在独立终端中运行、重启、构建或清理。

## 会话与运行时

- Claude Agent SDK 更新至 0.3.323。
- 修复聊天中的本地图片链接打开方式，以及部分无效图片响应后的会话恢复问题。
