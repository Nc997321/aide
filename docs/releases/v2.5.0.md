# Aide v2.5.0

本版为内置浏览器增加开始页和最近使用，串联已有的视频创作与媒体预览入口，并修复部分本地图片无法显示的问题。

## 新增

- **浏览器开始页**：新标签页直接展示创作入口和最近使用，可按网页、创作、媒体筛选记录；支持移除记录与撤销。
- **创作与媒体直达**：提供「制作短视频」「剪辑已有视频」「打开媒体」入口。创作要求追加到当前会话草稿，保留已有内容，由用户确认发送，不自动启动渲染。
- **最近工作接续**：创作记录回到原会话；媒体通过源文件重新打开，不保存会过期的临时播放地址。记录按 Host 隔离保存。
- **网站图标**：最近网页与历史记录优先使用本地图标缓存；没有缓存时加载网站自身的标准图标，失败后保留地球占位，不使用第三方图标聚合服务。

## 界面与交互

- 新增浏览器右上角三点菜单，集中提供新标签页、收藏夹、历史记录与导入收藏。
- 收藏栏默认隐藏，「显示收藏栏」开关移入收藏夹内部，并记住用户选择。
- 空地址栏的「输入网址」提示居中；实际输入的网址仍左对齐，方便编辑。
- 开始页适配窄栏与明暗主题；打开菜单或弹窗时，原生网页正确让位。
- 浏览器工具支持有界的连续操作，遇到失败或不确定结果及时停止，并提供操作后的状态证据。

## 修复

- 修复回复中 `/C:/…`、`/D:/…` 等 Windows 本地图片路径带有额外 URL 斜杠时无法显示的问题；保留正常 POSIX 路径与图片文件名转义处理。
- 修复最近网页始终使用地球占位、没有接入已有网站图标缓存的问题。
- 空白地址栏不再尝试打开无效网址，空标签页的收藏按钮保持禁用。
- 补充鸿蒙端供应商图标资源。

## 使用说明

- 最近使用记录从本版本启用后开始积累，不扫描旧会话补造历史。
- 尚未发送的新草稿只在当前运行期间保留记录；新会话确认身份后，相关记录才会持久保存。
- 本次提供 Windows x64 安装包；选择 `.exe` 或 `.msi` 安装即可，不需要同时安装两种格式。
