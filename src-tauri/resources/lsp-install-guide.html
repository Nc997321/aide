LSP 服务器安装向导

Aide 内置 LSP（语言服务器）功能需要各语言的 server 二进制。本页说明怎么装、装完怎么验证。

最省事的办法：TypeScript / JavaScript、Python、Rust 在插件市场 →「语言服务器」里一键安装， 装到当前窗口连着的机器（本机、WSL、SSH 各装各的），装完立即生效，不用改 PATH、不用重启。 标题栏「语言环境」面板里显示「未安装」的那一行也有「一键安装」按钮。下面的手动步骤用于其它语言，或你想自己管理版本时。
手动安装：查找顺序是 设置里手动指定的路径 → 插件市场装的语言包 → PATH 发现。装完对应 server 后： 重启 Aide → 打开项目 → 标题栏 LSP 徽章 → 开 LSP 开关 → 该语言应显示 ✓ 就绪。 没装的会显示 ✗ 未安装 并弹 "LSP server not found" 提示，这是预期行为。
快速自检 Rust TypeScript / JS Vue Go Java Python Kotlin 更多语言 排错

① 快速自检：本机装了哪些

在终端（PowerShell / CMD）逐条运行，有路径输出 = 已装：

where rust-analyzer typescript-language-server gopls jdtls pyright-langserver kotlin-language-server

更快的方式：打开 Aide → 标题栏 LSP 徽章 → 面板直接显示每语言状态（✓ 就绪 / ✗ 未安装 / ! 启动失败）。

rust-analyzer

从 GitHub releases 下载对应平台可执行文件，放进 PATH 目录（Windows 放任意目录后加入 PATH）。

④ Vue / React 项目（.vue、.tsx）

不需要额外 server

.vue / .tsx / .jsx 都由上面那个 typescript-language-server 服务（同一门语言，多一种文件形态），面板上对应的是 TypeScript 行。

Vue 项目额外前提：项目自己装了 @vue/typescript-plugin（Volar 的 tsserver 插件形态， 通常随 vue-tsc / @vue/language-server 一起进来）。装了 Aide 会自动把它挂进 TS 服务器 （node_modules/@vue/typescript-plugin 存在即可）；没装则 .vue 不提供诊断/跳转，但 .ts 照常可用—— 这是探测不到插件时的如实降级，不是故障。
npm i -D @vue/typescript-plugin    # 项目里装（不是全局）

验证：装好后重开 Aide；打开一个 .vue 文件，在 .ts 里对某个符号查引用应能看到 .vue 里的用法。

独立的 vue-language-server（Volar）已不再支持：它是需要宿主桥接 tsserver 的 proxy， 我们接不动，装了也不出结果——所以别为它花时间。

⑥ Java

jdtls（Eclipse JDT Language Server）

jdtls需 JDK 21+
1. 安装（winget 无 jdtls 包，官方渠道手动下载）：

从 eclipse.jdt.ls releases（或官方持续构建 download.eclipse.org/jdtls/snapshots/）下载最新 zip/tar.gz → 解压到固定目录（如 C:\tools\jdtls）→ 把 bin/ 目录加入 PATH → 重开终端。

2. 不想动 PATH 时（设置覆盖）：

标题栏 LSP 面板 → 「服务器覆盖」→ 给 java 填 program 为 jdtls 可执行文件完整路径，args 留空即可（Aide 自动补 -data 工作区目录）。

3. 验证：

where jdtls 有输出即装好。然后重启 Aide → 打开 Java 项目 → 开 LSP → 面板 Java 显示 ✓。

4. 多 JDK 环境：把 jdtls 指向 JDK 21（实操）

为什么：jdtls 脚本从 PATH/JAVA_HOME 找 java。默认 JDK 是 8/17 时 jdtls 会用旧 JDK 启动失败（面板显示「! 启动失败」）。按下面步骤给 jdtls 单独指定 JDK 21——无需改全局环境变量

① 下载安装 JDK 21（推荐 Eclipse Temurin 21 LTS——免费、长期支持、Windows 有安装向导）

打开 adoptium.net/temurin/releases/?version=21 → 操作系统选 Windows → 架构 x64 → 下载 .msi 安装包（约 190MB）→ 双击安装，一路「下一步」（默认装到 C:\Program Files\Eclipse Adoptium\jdk-21.x.x-xx\）。

② 确认 JDK 21 的实际安装路径（版本目录名每个人不同，必须用真实路径）

资源管理器地址栏输入 %ProgramFiles%\Eclipse Adoptium 回车 → 记下里面的文件夹名（形如 jdk-21.0.6-11）。完整路径即 C:\Program Files\Eclipse Adoptium\jdk-21.0.6-11。下面示例用 <JDK21路径> 代替它。

③ 方法 A（推荐）：建 wrapper 脚本

建文件夹 C:\jdtls\，在里面新建文本文件改名为 jdtls21.bat，用记事本粘贴保存（注意编码选 ANSI 或 UTF-8 无 BOM）：

@echo off
set JAVA_HOME=<JDK21路径>
jdtls %*

测试：打开终端运行 C:\jdtls\jdtls21.bat——若 jdtls 正常起进程（无 java 版本报错）即成功，按 Ctrl+C 退出。

④ 在 Aide 里配置（方法 A）

标题栏 LSP 徽章 → 打开面板 → 下方「服务器覆盖」→ 语言 java 行：program 填 C:\jdtls\jdtls21.bat，args 留空（Aide 自动补 -data）→ 保存。

⑤ 方法 B（免脚本，用 -vm 参数）——不想建文件就用这个：

标题栏 LSP 面板 → 「服务器覆盖」→ 语言 java 行：program 填 jdtls 脚本完整路径（如 C:\tools\jdtls\bin\jdtls），args 填：

-vm <JDK21路径>\bin\java.exe

⑥ 验证：重启 Aide → 打开 Java 项目 → 标题栏 LSP 徽章 → 开 LSP 开关 → 面板 Java 显示 ✓ 就绪；打开 .java 文件看诊断/补全。

⑩ 排错（FAQ）

面板显示 ✗ 未安装，但我明明装了？

PATH 未生效：装完后需重开终端验证 where <server>；Aide 需要重启才能读到新 PATH（dev 模式跑 pnpm tauri dev 的还需要重新编译 Rust 后端）。仍不行就用设置覆盖填完整路径。

面板显示 ! 启动失败（handshake failed）？

server 找到了但初始化握手超时（默认 5s）。常见原因：首次启动慢（尤其 jdtls/rust-analyzer 第一次要建索引，属正常，多试一次）；server 版本与 JDK/Node 不匹配（jdtls 需 JDK 21+，`java -version` 确认）；被安全软件拦截（见下）。

装了 jdtls 还是报错？

确认 JDK 21+（java -version）；确认 where jdtls 找到的是 jdtls 脚本而不是别的同名命令。Aide 已特判：不传 --stdio（jdtls 默认 stdio）、自动补 -data。如果你自己配了 args，想自定义工作区目录就显式写 -data <目录>。

为什么项目目录里多了 .project / .classpath / .settings？

jdtls 是 Eclipse 内核，导入项目时会生成 Eclipse 项目元数据。**jdtls 1.54+ 已内置解决**：Aide 启动 jdtls 时注入 --jvm-arg=-Djava.import.generatesMetadataFilesAtProjectRoot=false，元数据自动重定向到项目内 .aide/jdtls-workspace/（源码目录零污染，该目录 Aide 文件树默认隐藏、不参与代码索引）。注意：升级前已生成的文件不会自动清理（重定向只对不存在的文件生效）——手动删一次项目里的 .project、.classpath、.settings/ 即可，之后不再生成。

为什么打开面板一直显示「正在探测项目语言…」？

探测会对每个语言拉起 server 握手（每语言最多 ~5s，串行）。语言多或 server 首次启动慢时等十几秒正常。若永远不结束：看 Aide 终端日志有没有 [lsp stderr] 输出；也可能被安全软件拦截了 server 进程的 spawn（把 Aide 加白名单）。

什么是「设置覆盖」？

标题栏 LSP 徽章 → 打开面板 → 「服务器覆盖」：给任意语言指定 program（完整路径）+ args（可选），优先于 PATH 发现。适合：server 不在 PATH、要指定特定版本、或要传自定义参数。例：java → program = C:\tools\jdtls\bin\jdtls，args 留空。

LSP 开关在哪？

标题栏 语言环境 徽章（显示「LSP 关」或语言状态）→ 点开面板 → 右上角开关。工作区级：每个项目独立记忆开关和排除目录。
